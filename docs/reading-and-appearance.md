# 阅读与外观配置

## 背景与配色

在站点 `_config.liquid.yml` 配置：

```yaml
background: /images/background.jpg
liquid:
  enable: true
  background:
    toggle: true
    light: '#f6f6f6'
    dark: '#1e1e1e'
```

右下角按钮切换纯色和图片背景，选择保存在浏览器中。首次访问默认纯色；已有图片模式偏好优先。图片模式使用半透明卡片，纯色模式使用实色卡片。新增按钮默认关闭，升级后按需开启。

主题的链接、目录、播放器和分享图标采用中性色彩。文章正文使用衬线字体，界面字体仍由 `font` 等主题配置控制。音乐播放器首次使用时收起，已有展开状态会保留。

## 阅读辅助

启用 `liquid.enable` 后，文章页自动加载阅读辅助：

- 当前最近一级章节（包括子标题）显示在导航下方；点击返回原始标题。
- 标题和目录跳转同步 URL 锚点，直接访问章节链接也可定位。
- 置顶层只绘制文字，背景来自同一张文章卡片；正文进入置顶区域后裁切，避免叠字。
- 鼠标悬停正文标题时显示 H1–H6 层级；导航文章名回到正文开头，返回箭头回到上一页。

目前阅读辅助面向完整页面加载；开启 PJAX 的站点应先验证跨文章导航，当前脚本尚未实现 PJAX 重新初始化。

## 复制为 Markdown

```yaml
copy:
  enable: true
```

启用 Liquid 和复制功能后，选中正文再复制会转换为 Markdown。内置 Turndown 和 GFM 浏览器资源，无需额外安装 npm 包。支持 KaTeX 公式源码、引用、代码围栏、链接和表格；输出是从页面结构还原的 Markdown，不保证与原文件逐字相同。

中文标点附近的强调解析属于 Markdown 渲染器配置，不由主题自动修改；若需要 `markdown-it-cjk-friendly`，应在站点项目单独安装并配置。

## 社交按钮与升级

社交配置沿用 `链接 || 标题 || 颜色`。链接留空而标题非空时，按钮会复制标题内容，可用于联系方式：

```yaml
social:
  fab fa-weixin: ' || your-wechat-id'
```

这次同步还包含系列页标题修复、公式摘要去重、目录排版、分享字体兼容与图片查看器改进。更新主题后执行 `hexo clean && hexo generate`。站点自己的导航菜单、联系方式、文章和歌单仍在站点配置中维护。
